# 世界伝統色辞典 (Sekai Dentōshoku Jiten)

日本・欧州に、中国・インド・ペルシャ、**アフリカ**、**南北アメリカ**の色を加えた、13の文化・1055色の色名辞典です。
ビルド不要の静的サイトで、`index.html` をブラウザで開くだけで動きます。

地域は三つのまとまりに分け、それぞれの地域の感性(何を色の名前にするか)を、画面で選ぶと紹介します。

### 地域の分け方
- **アフリカ**は、言語・染織・交易圏の違いが色の名前に出やすい四つに分けました。北(アラビア語圏と古代エジプト)、西(藍・泥染め・ケンテなど布と金)、東(サバンナ・インド洋・エチオピア高原)、中南部(最古の赭土、ビーズ、壁画、鉱物)。
- **アメリカ**は、感性の違いが大きい四つの系統を選びました。メソアメリカ(祝祭と鮮烈な対比)、アンデス(高地の染織と毛色)、北米先住民(大地・空・方角)、熱帯アメリカ(果実・密林・港町・オリシャ)。

## 使い方

`index.html` をダブルクリック。インターネット接続があるとWebフォント(Google Fonts)が読み込まれ、なくてもシステムフォントで表示されます。

### 機能
- **地域・系統・テーマで絞り込み** — 地域(13地域、またはアジア・欧州/アフリカ/アメリカのまとまり) × 桃/赤/橙/黄/緑/青/紫/茶/白黒 × テーマ(花・顔料・染料・宝石…)。件数は他の条件に応じて動的に変わります。地域やまとまりを選ぶと、その感性の紹介が出ます。
- **検索** — 名前・読み・ローマ字(原語)・HEX・由来・地域名を横断。ひらがな/カタカナ、長音記号 (`ū`) やアポストロフィの違いを吸収します。スペース区切りでAND検索。`/` キーで検索欄へ移動。
- **並び替え** — 掲載順 / 五十音 / 色相 / 明度 / 彩度(一覧は120枚ずつ描画し、末尾が近づくと自動で続きを足します)
- **表示形式** — グリッド / リスト / **分布図** (横軸=色相、縦軸=明るさ。複数の地域を表示しているときは、輪郭色と凡例で地域が分かります)
- **詳細** — 由来、HEX/RGB/HSL/CMYK(コピー可)、WCAGコントラスト、**他の文化での最も近い色**(近い6地域を表示、残りは折りたたみ)、配色の提案(補色・類似色・トライアドを最寄りの伝統色名で表示)、同地域の近い色。← → キーで前後移動。
- **近い色を探す** — 好きな色(カラーピッカー/HEX/スポイト)から、13の文化それぞれの最近傍をまとまりごとに表示。色差はCIEDE2000。
- **マイパレット** — ♡ で収集し、CSS変数 / HEX一覧 / JSON で書き出し。ブラウザ内(localStorage)に保存。
- **共有リンク** — 絞り込み条件と開いている色はURLの `#` 以降に入ります。
- ライト/ダークテーマ(OS設定に追従、手動切替可)、スマホ幅対応。

## ファイル構成

```
index.html              画面の骨組み
css/app.css             スタイル
js/app.js               アプリ本体
js/color-utils.js       色空間計算(RGB/HSL/Lab/CIEDE2000)・系統判定・検索正規化。Nodeからも利用可
js/data/{jp,eu,cn,in,ir}.js        色データ(アジア・欧州)
js/data/{naf,waf,eaf,saf}.js       色データ(アフリカ: 北・西・東・中南部)
js/data/{mes,and,nam,tro}.js       色データ(アメリカ: メソアメリカ・アンデス・北米先住民・熱帯アメリカ)
tools/check-data.js     データと色計算の検証 (node tools/check-data.js)
```

## 色を追加・修正する

`js/data/*.js` の配列に1行足します。

```js
// [名前, 読み, ローマ字(原語・英語の意味など), HEX, 由来・解説, テーマ]
["紅","くれない","Kurenai","#CB1B45","紅花で染めた、深く鮮やかな赤。","d"],
```

### 地域を増やす
1. `js/data/<id>.js` を作る(`(window.SEKAI = window.SEKAI || {}).<id> = [ … ];`)。
2. `js/app.js` の `REGIONS` に、`group`(`GROUPS` のどれか)・表示名・言語(`lang`、右から左の文字は `dir: 'rtl'`)・地域色・紹介文を足す。
3. `index.html` に `<script src="js/data/<id>.js">` を足し、`tools/check-data.js` の `REGIONS` にも `<id>` を足す。

テーマ記号: `f`=花・草木 `m`=鉱物・顔料 `d`=染料・織物 `a`=動物・鳥 `n`=空・水・自然 `t`=食・香辛料 `g`=宝石・金属 `c`=文化・儀礼

- 色の**ID は配列の並び順**(`jp-001` …)で決まります。マイパレットや共有リンクに使われるため、既存の色の途中への挿入や並べ替えは避け、**末尾に追加**してください。
- 追加後は `node tools/check-data.js` で、項目数・HEX形式・テーマ記号・重複を確認できます。

## 注意

- **HEX値は代表的な近似値です。** 染料・顔料・資料によって色味は大きく異なります。系統の分類とCMYKは計算による目安です。
- 色名・読み・解説は独自に編集したもので、参考にした色彩図鑑 (i-iro.com) のデータは使っていません。構成(系統別・テーマ別の探し方、色ごとの詳細ページ)のみ着想を得ています。
- 外国語の色名の翻字・カナ表記、由来の記述には慣用的な表記や諸説があります。誤りに気づいたら `js/data` で直接修正できます。
- アフリカとアメリカの色は、各地域の**代表的な例**です。一つの地域の中にも多くの言語と共同体があり、同じ色の名前や意味が異なります。名前の言語が混ざる地域(西・東・中南部アフリカ、熱帯アメリカ)では、行ごとに言語が違います。
- 先住民族の色の意味(北米の聖なる山の方角の色、マサイやズールーのビーズの色など)は、一般に紹介されている範囲にとどめ、「〜とされる」と記しました。民族ごと、作り手ごとに異なります。
